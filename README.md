# NovaBank AI Support Agent & Landing Page

Интеллектуальный ИИ-консьерж цифрового необанка **NovaBank** с клиентской архитектурой **BYOK (Bring Your Own Key)** на базе Google Generative AI REST API (линейка моделей Gemini 3.x).

🌐 **Онлайн демонстрация (GitHub Pages):** [https://russell2204.github.io/novabank-ai-support-agent/](https://russell2204.github.io/novabank-ai-support-agent/)

---

## 🚀 Ключевые возможности

1. **Client-Side Only (Zero-Backend) Архитектура:**
   - Полная конфиденциальность: API-ключ Google AI Studio и все диалоги хранятся исключительно в браузере пользователя (`localStorage` или `sessionStorage`).
   - Запросы к Gemini API отправляются напрямую с клиента на эндпоинты Google (`https://generativelanguage.googleapis.com/v1beta/`).

2. **Матрица моделей ядра Gemini (строго 3.5, 3.6, 3.8):**
   - **Gemini 3.5 (Flash Speed):** Мгновенные краткие справки (< 0.8с), температура `0.2`, блокировка утерянных карт, проверка лимитов.
   - **Gemini 3.6 (Pro Balance):** Сбалансированный режим, Markdown-таблицы тарифов, расчет кэшбэка, температура `0.4`.
   - **Gemini 3.8 (Deep Reasoning):** Глубокая финансовая аналитика, точные формулы аннуитетного платежа, сложные стратегии сбережений, температура `0.6`.
   - Бесшовное переключение моделей в 1 клик с добавлением системного разделителя и сохранением истории сообщений.

3. **Интерактивный финансовый чат-виджет (640px):**
   - Потоковый стриминг ответов (SSE) в реальном времени.
   - Защищенный парсер Markdown с экранированием XSS-сущностей, поддержкой таблиц, списков, цитат, блоков кода и автолинковкой телефонов.
   - Чипсы быстрых промптов (Quick Prompts Bar) и тактильные сценарии в Hero-секции.
   - Автоматический скролл, индикатор набора текста и визуальная обратная связь.

4. **Двухконтурная эскалация на живого менеджера 24/7:**
   - **Контур А (сложные кейсы):** Автоматическая маршрутизация на звонок менеджеру (`8 (800) 555-01-99`) при подозрении на мошенничество, чарджбэке, блокировках, крупных сделках.
   - **Контур Б (отказоустойчивость):** При перегрузке Google API (503), исчерпании лимитов (429) или сбое сети интерфейс выводит карточку вызова дежурного специалиста и модальное окно заказа обратного звонка за 5 минут.

5. **BYOK Gate & Безопасная валидация ключа:**
   - Двухуровневая проверка: поддержка новых и классических форматов ключей Google AI Studio + сетевой ping.
   - Автоматическое маскирование ключей в URL и консоли (`key=REDACTED`).
   - Кнопка мгновенного удаления ключа из памяти браузера («Сбросить ключ»).

6. **Продуктовая экосистема NovaBank:**
   - Дебетовая карта **Nova Zero** (0 у.е./мес, 5% кэшбэк).
   - Премиальная карта **Nova Black** (10% Travel, залы DragonPass).
   - Накопительный счет **Nova Сейф** (14.0% APY, ежедневная капитализация).
   - Кредит **Nova Спринт** (от 16% годовых, аннуитетный калькулятор).
   - Ипотека **Nova Ипотека** (от 6.0% годовых, семейная и IT-программы).

## 💻 Быстрый запуск

### Вариант 1: Через Python (уже установлен в системе)
В терминале проекта выполните:
```bash
python -m http.server 3000
```
Затем откройте в браузере: [http://localhost:3000](http://localhost:3000)

### Вариант 2: Через npm
```bash
npm.cmd start
```

## 🔑 Инструкция по тестированию (DoD Checklist)

1. **Экран блокировки (BYOK Gate):**
   - Откройте приложение в режиме инкогнито или без сохраненного ключа.
   - Убедитесь, что чат заблокирован слоем BYOK Gate, а в шапке отображается статус `🔴 Ключ не подключен`.
   - Введите заведомо ложный ключ (например, `12345`) — система заблокирует его и выведет ошибку валидации.

2. **Авторизация:**
   - Введите валидный ключ Google AI Studio из [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey).
   - После подтверждения чат разблокируется, в шапке загорится `🟢 Агент активен`, появится кнопка «Сбросить ключ».

3. **Переключение моделей:**
   - В верхней панели чата переключайтесь между **Gemini 3.5**, **Gemini 3.6** и **Gemini 3.8**.
   - В историю сообщений будет добавляться стильный разделитель с описанием активного профиля без потери предыдущей переписки.

4. **Проверка базы знаний NovaBank:**
   - Задайте вопрос: *«Сколько стоит обслуживание карты Nova Black и какой там кэшбэк?»*
   - Бот ответит строго по базе знаний: 25 у.е./мес (или 0 у.е. при выполнении условий), 10% на путешествия, авиабилеты и рестораны, 2% на остальное.

5. **Безопасность:**
   - Откройте вкладку Network в инструментах разработчика браузера (F12) и убедитесь, что запросы уходят исключительно на домен `generativelanguage.googleapis.com`.
   - Нажмите кнопку «Сбросить ключ» в шапке — данные мгновенно удаляются из `localStorage` и `sessionStorage`.
